# Backlog — Archiv

> **Nicht mehr pflegen.** Die Aufgabenverwaltung läuft ausschließlich über
> [GitHub Issues](https://github.com/dimto13/ai-tutor-lab/issues) und das
> [Project „AI Tutor – Development“](https://github.com/users/dimto13/projects/3).

Die Dateien in diesem Ordner (`backlog.yaml`, `tickets.csv`) und `docs/06-backlog.md`
dokumentieren den Planungsstand vom 2026-08-08, mit dem das Backlog erstmals als Issues
angelegt wurde. Sie bleiben als Nachvollziehbarkeit der ursprünglichen Planung erhalten,
sind aber **nicht mehr autoritativ**: Ein Ticket, das hier steht, kann in den Issues längst
geändert, geschlossen oder ersetzt worden sein.

Die zugehörige Automatisierung (Sync-Workflow und `scripts/sync_github.py`) wurde entfernt,
weil ein versehentlicher Lauf die manuell gepflegten Issues überschrieben hätte.

Neue oder geänderte Aufgaben gehören direkt in ein Issue — siehe
[`docs/README.md`](../docs/README.md#aufgabenverwaltung-mit-github).
